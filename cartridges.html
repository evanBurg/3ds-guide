🎴 Physical cartridges

Turn a cartridge in the slot into a file on the SD card: a 3DS game becomes an installable CIA, a DS game becomes a ROM — which can then get its own Home Menu icon too.

Dumping a cartridge you own is fine. It's just a personal backup — the point here is to stop needing the physical cart in the slot, not to share the file.

3DS cartridge → CIA, with GodMode9

This makes a legit CIA from your own cartridge's actual data, so it installs and plays exactly like a digital game, box art and all.

  1. Put the cartridge in the slot, power the console fully off
  2. Hold Start and power on to reach the payload menu, then choose GodMode9
  3. Select GAMECART
  4. Press A on the game entry → Copy to 0:/gm9/out
  5. Go to 0:/gm9/out, press A on the dumped file → NCSD image options → Build CIA from file
  6. The finished CIA lands in /gm9/out/ — install it in FBI like any other CIA

DS cartridge → ROM, with GodMode9i

DS carts need a different tool: GodMode9i, the DS-mode counterpart to GodMode9, launched from inside TWiLight Menu++.

  1. Put the DS cartridge in the slot
  2. Open TWiLight Menu++ and launch GodMode9i from its extras
  3. Select NDS GAMECARD
  4. Press A, then A again to dump the cart
  5. The .nds file lands in /gm9i/out/ on the SD card
  6. Move it into /roms/nds/ — TWiLight Menu++'s game list picks it up from there like any other DS game

Give it a Home Menu icon, with NDSForwarder

TWiLight Menu++'s game list works fine on its own, but a forwarder is a small CIA that launches straight into one specific DS game, so it gets its own icon on the Home Menu instead of living inside TWiLight Menu++'s list.

  1. Make sure the game's .nds file is already in /roms/nds/
  2. Open the Homebrew Launcher and launch NDSForwarder
  3. Browse to the .nds file and press A
  4. Confirm with Yes to install
  5. The game now has its own icon on the Home Menu, right next to everything else
Want a proper box-art icon instead of the default one? Drop a 4-bit BMP with the same name as the ROM alongside it before generating the forwarder, and NDSForwarder uses that instead.
If a forwarder won't launch, it's almost always the nds-bootstrap forwarder pack missing or out of date on the SD card, not the forwarder CIA itself. Reinstall the pack that came with NDSForwarder.
