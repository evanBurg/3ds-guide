📦 Installing apps

How homebrew gets onto your console, and how to keep it updated.

The two file types

Homebrew comes in two formats. This trips everyone up once, then never again.

.cia.3dsx
What it isA real installed appA loose program file
Where it appearsIcon on your Home Menu, like any gameOnly inside the Homebrew Launcher
How to installOpen it in FBI → Install and delete CIADrop the file in /3ds/ on the SD card
Uses install spaceYesNo
Rule of thumb: if an app offers a .cia, take it. It puts a normal icon on your Home Menu and is easier to launch. Only use .3dsx when that's the only option.

Installing a .cia with FBI

  1. Open FBI from your Home Menu
  2. Select SD
  3. Browse to the folder holding the file
  4. Press A on the file → Install and delete CIA
  5. Wait. The icon appears on your Home Menu.
To install a whole folder at once: enter the folder by selecting it, then choose the option that says <current directory>, then select Install and delete CIA.

Universal Updater your app store

This is the app you'll use most. It's a browsable catalogue of 3DS homebrew that downloads and installs in one step, with no computer involved.

  1. Open Universal Updater
  2. Browse or search
  3. Press A on an app, pick the .cia download
  4. It installs itself

Every app on your console came from here, so it's also how you update them later. If something seems out of date, check here first.

Running a .3dsx

These live in /3ds/ on the SD card and only appear inside the Homebrew Launcher. Open that from your Home Menu, and you'll see a list of everything in that folder.

On your console, Balatro is the one app that works this way.
