📡 Moving files

Two ways. The SD card is faster for bulk transfers; FTP is far more convenient for one or two files.

Wirelessly from an Android phone no cable

ftpd turns the 3DS into a file server on your Wi-Fi.

  1. Connect the 3DS to the same Wi-Fi as your phone
  2. Open ftpd on the 3DS — it displays an address like 10.0.0.236:5000
  3. On Android, install an FTP-capable file manager. CX File Explorer and Material Files are both free and work well.
  4. Add a new FTP connection:
    • Host: the IP shown on the 3DS
    • Port: 5000
    • Anonymous — no username or password
  5. You're now browsing the SD card. Copy files into /roms/… or /cias/ as needed.
Leave ftpd open on the 3DS while transferring; closing it drops the connection. For anything large, the SD card is much quicker.

By SD card

  1. Power the console fully off — hold Power, then Power Off. Not sleep.
  2. Take the SD card out and put it in a computer
  3. Copy files into the right folder
  4. Safely eject, put it back, power on
Never remove the SD card while the console is on or sleeping. That's the most common way people corrupt a card.
