Virtual Console injections primary method

An injection is a ROM rebuilt into a .cia that Nintendo's real Virtual Console emulator runs, so it plays with the accuracy of the original hardware and gets a normal box-art icon on your Home Menu — not a generic emulator icon. It's how most games are played on this console now.

The catch: building one takes a Windows computer. The tool is New Super Ultimate Injector (NSUI).

  1. On a computer, open NSUI and start a new project
  2. Import the ROM — NSUI reads it and fills in most details automatically
  3. Click Download title screen from database for box art, or set your own icon
  4. Build the CIA
  5. Copy the finished .cia to the SD card (or send it over Wi-Fi with ftpd)
  6. On the 3DS, install it in FBI exactly like any other CIA
Pokémon and other GBA games with battery saves work fine now. NSUI injects the real-time clock and larger save sizes these games need, so there's no separate patching step first.
Neo Geo can't be injected. The 3DS never had a Neo Geo Virtual Console, so there's no base to inject into. Neo Geo always runs through RetroArch, below.

Nintendo DS: TWiLight Menu++

DS isn't a Virtual Console system — the 3DS runs DS games on its own real DS hardware. Put .nds files in /roms/nds/, then open TWiLight Menu++ from your Home Menu and pick a game. Compatibility is very high since nothing is being emulated.

Press Y on a game for per-game settings if one misbehaves.

Got a physical DS cartridge? See Physical cartridges for dumping it to the SD card, and optionally giving it its own Home Menu icon.

GBA fallback: open_agb_firm

If you'd rather not inject, open_agb_firm uses the 3DS's real GBA hardware directly, giving perfect accuracy without a computer. The catch is it takes over the console, so you reboot to switch games — an injected GBA game avoids that entirely.

  1. Power the console fully off
  2. Hold Start and power on
  3. Choose open_agb_firm
  4. Browse to /roms/gba/ and pick a game
  5. To leave, power off and boot normally

Saves are written to the SD card automatically, and save types are detected for you.

Pokémon Unbound is already installed, at /roms/gba/Pokemon Unbound.gba. It's a large fan-made ROM hack of Pokémon FireRed with a new region, story and difficulty modes. Launch it the way described above.

SNES fallback: Snes9x

Put .smc or .sfc files in /roms/snes/ and open Snes9x. This standalone app is noticeably faster than RetroArch's SNES cores on an original 3DS, so prefer it over RetroArch when not injecting.

Press Select in-game for the menu: save states, controls, and per-game cheats.

Everything else: RetroArch

RetroArch is one app that loads a separate core for each system. It's the fallback for NES, Genesis, Game Boy / Color, and the only option for Neo Geo. Your console has these installed:

CoreSystem
FB Alpha 2012 Neo GeoNeo Geo
GambatteGame Boy / Game Boy Color
FCEUmmNES
PicodriveGenesis / Mega Drive
Genesis Plus GXGenesis, more accurate but slower
Snes9x 2005SNES backup, prefer the standalone Snes9x or an injection

To play something: Load Core → pick the core → Load Content → find your game.

Neo Geo needs a BIOS. Neo Geo games won't start without a neogeo.zip BIOS file sitting alongside them in /roms/neogeo/. Keep the games zipped, don't extract them.
