🕹️ Playing games

Different systems use different apps. The table below is the whole answer.

SystemUsePut games in
Nintendo DSTWiLight Menu++/roms/nds/
Game Boy Advanceopen_agb_firm/roms/gba/
SNESSnes9x/roms/snes/
Neo GeoRetroArch → FB Alpha Neo Geo/roms/neogeo/
Game Boy / ColorRetroArch → Gambatte/roms/gb/, /roms/gbc/

Those folders already exist on your SD card. Drop game files straight in, no renaming, no setup. See Moving files for how to get them there.

Nintendo DS: TWiLight Menu++

Put .nds files in /roms/nds/, then open TWiLight Menu++ from your Home Menu and pick a game. It runs DS games on the console's real DS hardware rather than emulating them, so compatibility is very high.

Press Y on a game for per-game settings if one misbehaves.

Game Boy Advance: open_agb_firm

GBA works differently. The 3DS has real GBA hardware inside, and open_agb_firm uses it directly, giving perfect accuracy and battery life. The catch is it takes over the console, so you reboot to switch games.

  1. Power the console fully off
  2. Hold Start and power on
  3. Choose open_agb_firm
  4. Browse to /roms/gba/ and pick a game
  5. To leave, power off and boot normally

Saves are written to the SD card automatically, and save types are detected for you.

Pokémon Unbound is already installed, at /roms/gba/Pokemon Unbound.gba. It's a large fan-made ROM hack of Pokémon FireRed with a new region, story and difficulty modes. Launch it the way described above.

SNES: Snes9x

Put .smc or .sfc files in /roms/snes/ and open Snes9x. This standalone app is noticeably faster than RetroArch's SNES cores on an original 3DS, so use it rather than RetroArch for SNES.

Press Select in-game for the menu: save states, controls, and per-game cheats.

Everything else: RetroArch

RetroArch is one app that loads a separate core for each system. Your console has these installed:

CoreSystem
FB Alpha 2012 Neo GeoNeo Geo
GambatteGame Boy / Game Boy Color
FCEUmmNES
PicodriveGenesis / Mega Drive
Genesis Plus GXGenesis, more accurate but slower
Snes9x 2005SNES backup, prefer the standalone Snes9x

To play something: Load Core → pick the core → Load Content → find your game.

Neo Geo needs a BIOS. Neo Geo games won't start without a neogeo.zip BIOS file sitting alongside them in /roms/neogeo/. Keep the games zipped, don't extract them.

A note on "Virtual Console injections"

You may see guides about injecting retro games so they appear as real Home Menu icons. It's a legitimate technique, but on your setup it's mostly unnecessary work: the apps above already play these systems, and injection needs a Windows tool plus a rebuild for every single game.

Two things worth knowing:

  • Neo Geo cannot be injected. The 3DS never had a Neo Geo Virtual Console, so there's no base game to inject into. Neo Geo runs through RetroArch, as above.
  • GBA is the one case where injection genuinely wins, because injected GBA games get Home Menu icons and don't need a reboot. The standard tool is New Super Ultimate Injector (Windows only).
