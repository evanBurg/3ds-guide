Start here

Your 3DS runs Luma3DS, a custom firmware. It still works exactly like a normal 3DS — everything you had before is still there. It can now also run homebrew apps and games from older consoles.

Nothing is broken

Your games, saves, and eShop purchases all still work. Custom firmware sits underneath and stays out of the way.

The SD card is everything

All homebrew, games, and themes live on the SD card. Always power the console fully off before removing it.

You can't easily break it

A full backup of your console exists. See Safety & backups for what it is and where it lives.

First thing to do: open FBI on your Home Menu, go to SD → cias, and install everything in that folder. That sets up all the apps below. Instructions in Installing apps.

The three menus worth knowing

These are button combos, not icons. They're the main things that separate a modded 3DS from a stock one.

ComboWhenWhat you get
L+↓+Select Any time, even mid-game Rosalina — screenshots, cheats, and system tools
Hold Select While powering on Luma config — firmware settings. You rarely need this.
Hold Start While powering on Payload menu — launches GodMode9 and the GBA player

Rosalina most useful

Press L+↓+Select at any time. The game pauses and a text menu appears.

  • Take screenshot — saves to /luma/screenshots/ on the SD card
  • Cheats — per-game cheat codes, if available
  • Process list, Debugger — advanced, ignore these

Press B to back out, and L+↓+Select again to close and resume.

Payload menu

Hold Start as you power on. You get a short list:

  • GodMode9 — a file manager and backup tool that runs outside the operating system. Powerful; don't poke around unless following a guide.
  • open_agb_firm — plays Game Boy Advance games. See Game Boy Advance.

Installing apps

The two file types

Homebrew comes in two formats. This trips everyone up once, then never again.

.cia.3dsx
What it isA real installed appA loose program file
Where it appearsIcon on your Home Menu, like any gameOnly inside the Homebrew Launcher
How to installOpen it in FBI → Install and delete CIADrop the file in /3ds/ on the SD card
Uses install spaceYesNo
Rule of thumb: if an app offers a .cia, take it. It puts a normal icon on your Home Menu and is easier to launch. Only use .3dsx when that's the only option.

Installing a .cia with FBI

  1. Open FBI from your Home Menu
  2. Select SD
  3. Browse to the folder holding the file (yours are in cias)
  4. Press A on the file → Install and delete CIA
  5. Wait. The icon appears on your Home Menu.

To install a whole folder at once, highlight the folder itself and choose Install and delete all CIAs. That's the fast way to do the cias folder and the cias/cores folder.

Universal Updater your app store

This is the app you'll use most for maintenance. It's a browsable catalogue of 3DS homebrew that downloads and installs in one step, with no computer involved.

  1. Open Universal Updater
  2. Browse or search
  3. Press A on an app, pick the .cia download
  4. It installs itself

Every app on your console came from here, so it's also how you update them later. If something seems out of date, check here first.

hShop

Nintendo permanently closed the 3DS eShop in March 2023. There is no official way left to buy digital 3DS games. hShop is a community archive that hosts 3DS titles, and 3hs is its app for downloading them straight to your console.

hShop hosts commercial games. Downloading titles you don't own is copyright infringement in most countries. Your call — just know what it is.

Using 3hs

  1. Connect the 3DS to Wi-Fi
  2. Open 3hs
  3. Search or browse by category
  4. Press A on a title → it downloads and installs itself

It handles updates and DLC automatically, queues multiple downloads, and can keep downloading in sleep mode.

Custom themes

Anemone3DS changes your Home Menu look and your boot splash. The easiest route needs no computer at all.

Straight from the console easiest

  1. Open Anemone3DS
  2. Press L to open the Theme Plaza browser
  3. Find a theme, press A to download it
  4. Back in your list, press A to install

From a computer

  1. Download a theme .zip from Theme Plaza
  2. Drop the .zip — don't unzip it — into /themes/ on the SD card
  3. Open Anemone3DS and install it
FolderHolds
/themes/Home Menu themes
/splashes/Boot splash screens

Both folders already exist on your card. Anemone also handles badges and can preview anything before you commit with Y.

Those folders already exist on your SD card. Drop game files straight in — no renaming, no setup.

Nintendo DS — TWiLight Menu++

Put .nds files in /roms/nds/, then open TWiLight Menu++ from your Home Menu and pick a game. It runs DS games at full speed on real hardware, not emulation, so compatibility is very high.

Press Y on a game for per-game settings if one misbehaves.

Game Boy Advance — open_agb_firm

GBA works differently: the 3DS has real GBA hardware inside, and open_agb_firm uses it directly. Perfect accuracy and battery life, but it takes over the console, so you reboot to switch games.

  1. Power the console fully off
  2. Hold Start and power on
  3. Choose open_agb_firm
  4. Browse to /roms/gba/ and pick a game
  5. To leave, power off and boot normally

Saves are written to the SD card automatically, and save types are detected for you.

Pokémon Unbound is already installed, at /roms/gba/Pokemon Unbound.gba. It's a large fan-made ROM hack of Pokémon FireRed with a new region, story, and difficulty modes. Launch it the way described above.

SNES — Snes9x

Put .smc or .sfc files in /roms/snes/ and open Snes9x. This standalone app is noticeably faster than RetroArch's SNES cores on an original 3DS, so use it rather than RetroArch for SNES.

Everything else — RetroArch

RetroArch is one app that loads a separate core for each system. Your console has these installed:

CoreSystem
FB Alpha 2012 Neo GeoNeo Geo
GambatteGame Boy / Game Boy Color
FCEUmmNES
PicodriveGenesis / Mega Drive
Genesis Plus GXGenesis (more accurate, slower)
Snes9x 2005SNES backup — prefer the standalone Snes9x

To play something: Load Core → pick the core → Load Content → find your game.

Neo Geo needs a BIOS. Neo Geo games won't start without a neogeo.zip BIOS file sitting alongside them in /roms/neogeo/. Keep games zipped — don't extract them.

A note on "Virtual Console injections"

You may see guides about injecting retro games so they appear as real Home Menu icons. It's a legitimate technique, but on your setup it's mostly unnecessary work: the apps above already play these systems, and injection requires a Windows tool plus a rebuild for every single game.

The one case where it genuinely wins is GBA, because injected GBA games run on the real hardware without rebooting. If you decide you want that, the standard tool is New Super Ultimate Injector (Windows).

Moving files onto the console

Two ways. The SD card is faster for bulk transfers; FTP is far more convenient for one or two files.

Wirelessly from an Android phone no cable

ftpd turns the 3DS into a file server on your Wi-Fi.

  1. Connect the 3DS to the same Wi-Fi as your phone
  2. Open ftpd on the 3DS — it shows an address like 192.168.1.115:5000
  3. On Android, install an FTP-capable file manager. CX File Explorer and Material Files both work and are free.
  4. Add a new FTP connection:
    • Host: the IP shown on the 3DS (e.g. 192.168.1.115)
    • Port: 5000
    • Anonymous / no username or password
  5. You're now browsing the SD card. Copy files into /roms/… or /cias/ as needed.
Leave ftpd open on the 3DS while transferring — closing it drops the connection. Big transfers are much quicker via the SD card in a computer.

By SD card

  1. Power the console fully off (hold Power, then Power Off — not sleep)
  2. Take the SD card out and put it in a computer
  3. Copy files into the right folder
  4. Safely eject, put it back, power on
Never remove the SD card while the console is on or sleeping. That's the most common way people corrupt a card.

Safety & backups

Your backup exists

During setup, a complete image of your console's internal memory (a NAND backup) was made and verified. If the console ever fails to boot because of a software problem, that file restores it.

It is not on the SD card — it's stored separately on a computer, because it contains your console's unique encryption keys. Ask whoever set this up if you ever need it.

One small file, essential.exefs, is kept on the SD card at /gm9/backups/. Leave it there. It's tiny and it's what recovers your data if the hardware ever dies.

Back up your game saves

Checkpoint copies save files for your games onto the SD card. Worth doing before you experiment with anything.

  1. Open Checkpoint
  2. Pick a game
  3. Choose Backup

Rules that keep it healthy

  • Power off fully before removing the SD card.
  • Don't delete files you don't recognise — especially boot.firm, boot.3dsx, or the boot9strap, luma, and gm9 folders. The console won't boot without them.
  • System updates are safe, but there's no reason to install one.
  • Keep a copy of the SD card. Cards fail. Copying the whole card to a computer occasionally costs nothing.
If it won't boot: don't panic and don't keep pressing buttons. A black screen usually means a missing or corrupt file on the SD card, which is recoverable. Take the card out, check it in a computer, and ask for help before trying anything drastic.
