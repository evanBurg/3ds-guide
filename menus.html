🎛️ Hidden menus

These are button combos, not icons. They're the main thing separating your console from a stock one.

ComboWhenWhat you get
L+↓+Select Any time, even mid-game Rosalina: screenshots, cheats, system tools
Hold Select While powering on Luma config: firmware settings. You rarely need this.
Hold Start While powering on Payload menu: GodMode9 and the GBA player

Rosalina most useful

Press L+↓+Select at any time. The game pauses and a text menu appears.

  • Take screenshot: saves to /luma/screenshots/ on the SD card
  • Cheats: per-game cheat codes, when available
  • Process list, Debugger: advanced, ignore these

Press B to back out, and the same combo again to close and resume your game.

Payload menu

Hold Start as you power on. You get a short list:

  • GodMode9: a file manager that runs outside the operating system. Powerful, and capable of breaking things; don't poke around unless you're following a guide.
  • open_agb_firm: plays Game Boy Advance games. See Playing games.

Luma config

Hold Select as you power on. These are custom firmware settings, and the defaults are correct for your console. There is no reason to change anything here unless a guide tells you to.

Press Start to save and continue booting.

If you end up in one of these menus by accident, powering the console off and on again is always safe. Nothing here changes until you confirm it.
